## 2. 对手：每回合一次调用（U1、A1、A2）

**调用**：轮到对手，TableRunner 把该座位视角写进输入：阶段、底牌、公共牌、底池（含本轮未收的下注）、需跟注、可选行动与加注到的范围、各座位公开状态、本手行动、最近 8 条公屏、本地胜率参考（蒙特卡洛 150 次）、本桌最近 3 手公开结果摘要、该角色的记忆文档。只开放工具 `act({ action: 'fold'|'check'|'call'|'raise', to?, say?, note? })`：`raise` 在无人下注时即下注，`to` 为下注/加注到的总额。`toolChoice: 'required'`（提供方不支持时 `auto`），`maxSteps: 1`；同一步多次 `act` 只取第一次。

**规范化**（AI 决定，沿用现有纠正规则）：需跟注为 0 时 `fold`/`call` 视为 `check`；面对下注时 `check` 视为 `call`；不能加注时 `raise` 视为 `call`（或 `check`）；`to` 缺失取最小值，越界夹紧到合法范围；按当前是否已有下注映射为引擎的 `bet` 或 `raise`。规范化之后的动作引擎必定接受（压测覆盖）。

**发言**：提示词写“想说就在 `say` 里说一句，不超过 20 字，符合人设；可以虚张声势、谈论牌面，但不要如实报出自己的底牌；不说就留空”。代码只截断 `say` 到 40 字。只在自己回合说话：赢家不发言，无公屏回应，玩家不发言。

**记忆**（A2，AI 决定具体做法）：Mastra 的 working memory 需额外工具调用，Observational Memory 需后台额外调用且默认积累约 3 万 token 才压缩，均不合适。自己维护：`act.note`（≤30 字，截断）是“对某人的新观察或自己心情”，提示词要求只在有新观察时填写；每个角色每手最多追加 1 条（取本手最后一条），存 `river_memory`，每角色保留最近 10 条，跨桌共享。

**重试与停下**（A1）：对手 Agent 构造时显式 `maxRetries: 2`——审阅 2 F1 核实 Mastra 1.69 的 Agent 在未设置时 `maxRetries ?? 0`，默认不重试（note 已更正）。可重试的是网络错误与提供方标记可重试的错误（429/5xx），401/404 等直接失败，遵守 `Retry-After`（最多 30 秒）。每次决策整体限时 45 秒（含重试）。以下都直接停下（牌桌状态 `stalled`）：重试后仍失败、超时、模型没调用 `act`、模型未配置或密钥不可用。操作区上方横幅“阿狸 的模型调用失败：<原因>”，按钮「重试」（再发起一次，读取最新配置）与「去设置」（牌桌保留）。停下时离桌或退出应用：本手作废（引擎 `abortHand()` 恢复本手开始时的筹码），不落库，再按离桌结算（AI 决定）。

**思考速度**：改为最短显示时长：调用返回太快时补足到 0.4/0.9/1.5 秒再落子；设置说明改为“AI 行动的最短停顿”。

**删除**：`view_table`、`estimate_equity`、`read_chat`、`hand_history`、`say`、`recent_hands`、`view_hero`、`pause_game`、`hint` 工具与 `tools.ts` 的角色校验；`chatReply`、`pickResponders`、冷却、`winnerSpeech`；IPC `chat.send`；`agents/leak.ts`、`table/chat.ts`、`agents/queue.ts`、`agents/intents.ts` 中与之相关部分；消息的 `triggers`、`replyTo`、`autopilot`；角色的 `talk`、`lines`、`profile`；`LINES`；`decide()`；设置 `engine`、熔断、托管计数与横幅；`AgentDeps.appendResult`、`appendThreadMessage`、`resetMemories`、`test/db-mastra.test.ts`、`test/queue.test.ts`、`test/leak.test.ts`、`test/chat.test.ts`。

## 3. 教练与对局类型（U3、A3、A4、A8）

大厅“对局类型”分段控件：教练局 / 自由局，替换大厅“教练”开关；全局 `coachOn` 删除，类型是牌桌属性。教学牌局是教练局的一种（固定 3 人桌，提示词要求讲得更细），入口在大厅右侧卡片和引导页末页。

| | 教练局 | 自由局 |
| --- | --- | --- |
| 右栏 | 概率面板、教练发言、提问、复盘卡 | 只有概率面板 |
| 轮到玩家 | 操作锁定，教练说完再解锁 | 直接操作 |
| 一手结束 | 所有人底牌亮出（弃牌者半透明、标“已弃牌”，弃牌结束的手也亮），教练复盘 | 只亮摊牌的牌 |
| 下一手 / 重新买入 | 手动；复盘结束、失败或“跳过”后可点 | 手动 |
| 硬核模式 | 教练栏开关，隐藏概率面板 | 不适用，概率面板总显示 |

**同一时刻最多一个教练调用**（A4）：
- 轮到玩家：操作区锁定并显示“教练正在看牌…”与「不等了」。教练每次都说一段（A8），流式显示在教练栏：局面与本地计算写进输入，不开放任何工具，`maxSteps: 1`，限时 20 秒，`maxRetries: 1`。说完、失败（灰字“教练这次没连上”）或按「不等了」（中止调用）后解锁。
- 提问：只在教练空闲时可发；回答期间操作区同样锁定；回答流式显示；问答输入含当前局面，对话历史只带本桌最近 6 轮问答（教练发言和复盘不进历史），由 TableRunner 保存。流式输出开始后的中途错误不会被 Mastra 重试，显示「重试」。
- 一手结束：先亮全部底牌，然后复盘（工具 `recap({ headline, good, improve, tip, note? })`，`toolChoice: 'required'`，限时 45 秒，`maxRetries: 2`）。复盘中结果区显示“教练复盘中…”与「跳过」（中止调用）；复盘结束、失败（卡片上「重试」）或跳过后，「下一手」/「重新买入」才可点。每手必复盘、无开关（AI 决定；有「跳过」兜底）。
- 离桌：在途的教练调用中止；没完成复盘的手可在回放页发起复盘。
- 学员档案：`recap.note` 追加到 `river_memory` 的 `hero` 档案（与对手相同机制，保留 10 条），写进教练的系统提示。
- 复盘可以使用亮出的弃牌；对手读到的只有公开结果。
- 回放页“让教练复盘这一手”对教练局与自由局的手都可用（回放页不在牌桌上，A3 不涉及）。

设置页删除“自动下一手”“主动提醒”“每手复盘”。

## 4. 规则引擎（A5）

保留自研，改写为 `poker-ts` 风格的 `Table` 类（`src/main/engine/`）。

### 4.1 API

```ts
const t = new Table({ smallBlind: 50, bigBlind: 100 }, 6, rng)
t.sitDown(0, 10000)                  // 两手之间调用
t.startHand()                        // 按钮轮转到下一个有筹码的座位，发底牌，下盲注；筹码为 0 的座位本手不参与
while (t.isHandInProgress()) {
  while (t.isBettingRoundInProgress()) {
    const seat = t.playerToAct()
    const { actions, chipRange } = t.legalActions()   // actions ⊆ fold|check|call|bet|raise；可过牌时不含 fold；chipRange 为 bet/raise 到的总额
    t.actionTaken(action, betSize)   // 非法动作抛错（runner 先规范化）
  }
  t.endBettingRound()                // 收池并发下一街；只剩一人或所有人都无法再行动时按规则推进
  if (t.areBettingRoundsCompleted()) t.showdown()   // 只剩一人时不比牌，直接判给他
}
t.winners()                          // [{ pot, seat, amount, handName | null }]，只含真正赢到的底池；未被跟注部分不在其中
```

其他：
- 读状态：`button()`、`seats()`（每座 `{ stack, bet, startStack, folded, allIn, out }`）、`holeCards()`（返回全部底牌，按视角裁剪是 view 层的事，ADR-001 信息隔离不变）、`communityCards()`、`roundOfBetting()`、`pots()`（已收进的底池及资格座位）、`totalPot()`（含本轮未收的下注，概率面板与界面用）、`currentBet()`。
- 两手之间：`sitDown`、`standUp`、`setStack(seat, n)`（重新买入）。
- `abortHand()`：本手作废，所有座位筹码恢复到 `startStack`，本手结束且不产生赢家。
- `handLog()`：结构化条目 `{ street, seat, type: 'blind'|'fold'|'check'|'call'|'bet'|'raise'|'return', amount, to?, allIn }` 与 `{ street, board: Card[] }`；中文文案、VPIP/PFR 统计都由 runner 按条目生成，不再用正则匹配文案。
- 牌用 `'As'`、`'Td'` 字符串；`rng` 可注入；`evaluate`、`equity`、`outs`、`handName` 沿用现实现，作为独立函数导出。
- `endBettingRound` 是 runner 的节拍点：翻牌动效、全下后逐街发完（每街间隔 0.9 秒）都挂在这里。

### 4.2 规则修正（相对原型 `poker.js`）

| 问题 | 修正 |
| --- | --- |
| 短码不完整全下后，已行动者仍可再加注 | 不完整加注不重开已行动者的加注权；多次不完整全下累计达到一个完整加注额时重开；`legalActions` 与 `actionTaken` 判定一致 |
| 平分底池余数全给座位靠前的赢家 | 从按钮左侧起逐枚分配 |
| 未被跟注的下注、只有一人有资格的边池层被当作“赢得”（审阅 2 复现：摊牌输掉的大码出现在赢家里“赢得 8,000 · 高牌”） | 未被跟注部分直接退回（记 `return` 条目），不计入 `winners` |

死按钮、盲注补缴不做：对手破产后立即重新买入，桌上不会出现空位。

测试：保留原型对照用例中与修正无关的部分并标注修正项；新增规则用例（不完整加注、单挑顺序、边池、未跟注退还、余数分配、弃牌结束、`abortHand`）与随机压测（筹码守恒、每手能结束、`legalActions` 给出的动作与规范化后的任意动作 `actionTaken` 都接受）。

- 新建、编辑（名字、头像字、标签、简介、头像色、提示词）、删除、恢复内置、恢复默认；四项倾向删除。对手页副标题改为“每位对手由一段性格提示词驱动，改动从下一次行动生效”。

## 6. 用量与花费（A6）

- 现状：设置页模型列表来自 Mastra 包内静态注册表（源自 models.dev），没有价格，不连供应商接口。
- 价格：CI 构建时拉一次 `https://models.dev/api.json`，只截取价格字段，打进应用作为内置快照；应用启动时后台刷新一次（失败静默用快照或上次缓存）。按“提供方类型 + 模型 id”查价；查不到（如 OpenAI 兼容接口）只显示 token。`cost` 字段的存在与单位在首个任务中核实（本会话网络被拦截）。
- 记账：每次调用一行 `river_usage`：用途（对手决策、教练发言、教练问答、复盘）、`table_id`、`hand_no`、提供方类型、模型、输入/输出/缓存输入 token（可空）、时间。超时或中止记次数、token 为空。只存原始 token，显示时按当前价格计算；缓存输入先按输入价计，注明“估算”。
- 作废的手：用量计入总量，但不出现在每手花费柱状图。
- 显示：顶栏胶囊“本桌 $x”；部分模型无价时显示“$x + y token 未计价”；全无价时“本桌 y token”。统计页按设计稿的用量与花费区块，删除“公屏对话”“本地引擎兜底”“≈ ¥”换算，说明文字改为“token 来自提供方返回；价格来自 models.dev，仅供参考”。保留清零、每手花费柱状图、回放副标题中的花费。
- “清空记录”清手牌、复盘与余额，不清用量；用量只能用统计页“清零”。

## 7. 自动更新（A9，ADR-005）

- 依赖 `electron-updater`；`electron-builder.yml` 显式 `publish: { provider: github, owner: reflux-studio, repo: river }`；macOS 增加 `zip` 目标；macOS 用固定的自签代码签名证书签名（`CSC_LINK`、`CSC_KEY_PASSWORD` 存 GitHub Secrets），`hardenedRuntime` 仍关闭。
- CI：从 tag 注入版本号（`-c.extraMetadata.version=${tag#v}`）；自动发布为正式 Release（不再是草稿），上传安装包、`latest*.yml`、`.blockmap`。
- 行为：只在打包版本检查（开发环境跳过）；启动后与每 6 小时检查一次，后台下载；下载完在大厅顶栏显示“新版本 x.y.z 已就绪 · 重启更新”，只在大厅可点，牌桌中不打扰；未点则下次退出时安装（有桌时退出照旧先按离桌结算）。检查或下载失败静默。
- 首个任务在 macOS GitHub Actions 上验证：用同一张自签证书签两个版本，`codesign --verify -R` 满足旧版的 designated requirement，且 electron-builder 接受该身份。不通过则退回 ADR-005 的选项 B。
- 用户需做：生成证书、导出 p12、配置两个 Secrets（首个任务给出命令）；妥善备份证书，丢失即断更。
- 从 ad-hoc 切换到证书签名的那一版，可能需要重新输入一次 API key。

| 桌面外观、筹码堆、座位样式、动效三档、气泡、牌面小图、全下红色按钮、回放结构化复盘、自建对手、用量统计 | 按设计稿实现 |
| 停下横幅、更新提示、教练看牌中的锁定态与「不等了」、复盘「跳过」 | 设计稿没有，由 AI 按现有风格设计 |
| 没配模型时的入座入口（大厅入座、教学牌局、引导页“带我打一手”） | 统一跳转设置页并提示；教练局还要求教练模型 |

## 10. 一手的时序

```
startHand ─► 轮到对手 ─► act（maxRetries 2，限时 45s）─┬─ ok ─► 规范化 ─► 补足最短停顿 ─► actionTaken ─► 公屏（行动+发言）
                                                          └─ 失败 ─► stalled ─►「重试」/「去设置」/ 离桌（abortHand）
          ─► 轮到玩家 ─► [教练局] 锁定 ─► 教练发言（流式，≤20s，可「不等了」）─► 解锁 ─► 玩家行动（提问时再次锁定）
          ─► 本轮结束 ─► endBettingRound（翻牌动效）─► … ─► showdown
一手结束 ─► 落库 ─► 对手记忆追加 ─► [教练局] 亮全部底牌 ─► recap（可「跳过」）─► 「下一手」可点
```

## 11. 风险

| 风险 | 处理 |
| --- | --- |
| 小模型不调用 `act` | 直接停下，横幅提示可重试或换模型 |
| 教练局每步多等几秒 | A4 的取舍；「不等了」兜底；自由局不受影响 |
| models.dev 不可达或无价格字段 | 内置快照 + 缓存；仍没有就只显示 token |
| 自签证书方案在 macOS 不通过 | 首个任务验证；退回 ADR-005 选项 B |
| 规则修正让原型对照测试失效 | 对照测试逐条标注修正项 |
| 老用户升级后旧记忆不可见 | ADR-004 已说明不迁移 |

## 12. 不做

多人联机、账户与云同步、深色模式、Apple 公证。
