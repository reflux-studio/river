# River v2：归档

状态：已完成，归档于 2026-09-24，随 `v0.2.0` 发布。

## 交付

| 目标（plan §目标） | 结果 |
| --- | --- |
| 设计稿 `River v2.dc.html` 的交互与视觉 | 牌桌外观（桌布、牌背、动效三档）、筹码堆、座位样式、盲注与庄家标记、只读公屏、教练栏、复盘卡、大厅对局类型、AI 对手管理、回放、统计、设置（T6、T7） |
| 对手每回合一次 `act`；公屏只读；失败即停下 | 单次工具调用同时给出行动、台词、印象；Mastra 内置重试；失败时停下，可重试或去设置；停下时离桌作废本手（T4、T5） |
| 教练作为对局类型 | 教练局：每步先讲解、可暂停提问、一手结束亮全部底牌并复盘；自由局：只有概率面板（T5、T6） |
| 引擎 `Table` 类与三处规则修正 | poker-ts 风格 API；不完整加注不重开、余数从按钮左侧分配、未跟注退回（T2） |
| 真实用量与价格 | Mastra `totalUsage` + models.dev 价格；构建时快照、启动刷新；统计页用量；可选币种显示，汇率自动拉取（T3、T4、后续反馈） |
| 自动更新 | electron-updater + GitHub Releases；macOS 用固定自签证书签名（ADR-005，T1 在 CI 上验证更新链）（T8） |

## 关键决定

- ADR-004：去掉 Mastra Memory 与存储，记忆用最近 3 手 + 每角色 10 条印象。
- ADR-005：自签证书 + electron-updater，不做付费签名与公证。
- 讨论稿第 5 轮 §1：U1–U4、A1–A10（用户决定与 AI 决定）。

## 与方案的偏差

- 缓存 token 按 models.dev `cache_read` 价计费，而非“按输入价估算”（T4 结果）。
- 价格缓存存在 `river_kv.prices`，没有单独建表（T3 结果）。
- 原型的“200 手 legal/apply/摊牌对照”未保留，由规则用例替代（T2 结果）。
- 验收后按用户反馈追加：文字中牌面对齐、多币种与自动汇率（task.md“后续”）。
