# 006：将私有教练、手后全亮与场下透视分成独立政策

状态：接受（用户，2026-11-02）
依赖：001、002
影响模块：F1、F3、F5、F6、F9

## 背景

原单人 coach 模式同时控制讲解和手后全亮。多人娱乐局既需要私有教练，也提出场下透视与转播胜率，两者不能共享一个全局底牌开关。

## 可行选项

将教练与手后全亮合并为教学模式可沿用旧概念，但允许教练会同时改变其他人的底牌可见性。独立政策可按接收者和阶段控制，允许纯真人房保留自愿亮牌，并为场下观战提供单独投影。

## 决定与理由

coachAllowed 与 revealAllAfterHand 独立，多人默认均关闭。spectatorVision 纳入首版，娱乐房默认开启，仅已弃牌、待上桌与观战者获得额外底牌和真实牌面胜率。全下者仍在争池，不能获得透视。看过透视者不可于本手重新入局。

## 后果

同一权威状态需要多个可见性投影。教练只消费本人视图，旁路非阻塞；场下私有透视不等于手牌已对全桌公开。本地记录也区分公开揭示和观战可见数据，不能将额外信息扩散到仍在争池的玩家。未来牌堆顺序始终不提供给观战计算。
