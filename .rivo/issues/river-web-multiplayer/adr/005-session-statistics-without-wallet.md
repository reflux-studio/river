# 005：取消长期筹码钱包，按对局记录现金流与战绩

状态：接受（用户，2026-11-02）
依赖：001、004
影响模块：F1、F3、F4、F8

## 背景

项目原有 bankroll，讨论中曾建议本地统一余额。用户认为娱乐局总筹码无意义，要求桌面与 Web 同样只累计总买入、盈亏和按对局的趋势，并允许一场多次买入。

## 可行选项

保留统一钱包可维护跨房间余额，但引入充值/余额与转账语义。只维护各场筹码及现金流，则不限制娱乐买入，长期只保留个人历史统计。

## 决定与理由

采用对局与现金流模型，无跨房间总筹码资产。手牌与对局分别标识，一场内可多次买入；总盈亏和趋势从权威结算及买入/取回记录派生。

## 后果

已结束的场次以 cashOut - buyIn 为最终结果，未结束则分别显示已结算收益、剩余筹码和本手未结算投入。已结算手净收益与现金流要可核对，未结算投入不冒充已实现收益。最终字段与呈现需在方案明确。

手中买入/卖出已获确认，独立于回合，不记录玩家间债务；有效下注不撤回，已全下者不恢复本手下注资格，新买入下手可用（P36）。已有 bankroll 数据与页面需迁移或退役，不能把旧余额转成新盈利。历史记录保留，默认不删旧数据库。
