# 003：真人行动计时与 Agent 调用失败分别处理

状态：接受（用户，2026-11-02；补记）
依赖：001、002
影响模块：F3、F5、F7

## 背景

真人需要防挂机。现有 Agent 调用具有本地超时与重试，用户要求 AI 报错后房主可手动重试或移除。

## 可行选项

真人与 AI 共用房间行动截止时间，失败后自动执行默认动作，运行策略统一但可能将模型失败转成非预期弃牌。另一种是按控制端类型区分：真人使用牌桌计时，AI 使用本地调用超时，失败后由房主管理。

## 决定与理由

采用区分策略。真人超时可过则过否则弃牌，具体时长待细化；AI 在线但决策失败进入等待处理，不按真人超时自动弃牌。human/agent 控制端离线则独立按统一掉线期限移除，房主被移除时转让管理权。房主离线不等于 Agent 离线。用户认可移除阻塞 AI 时保留有效投入、手后离座的方向。

## 后果

AI 失败可能暂停牌局，需要房主在场或房主转移/结束规则。重试与移除使旧尝试失效。赛后聊天、亮牌等非阻塞任务失败不暂停全桌。具体管理性弃牌契约在方案细化。
