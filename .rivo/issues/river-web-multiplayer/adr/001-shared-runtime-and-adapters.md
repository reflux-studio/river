# 001：跨端共享权威运行核心与命令事件协议

状态：接受（用户，2026-11-02；补记）
依赖：无
影响模块：F1、F2、F3、F4、F5

## 背景

项目已有共享 engine、ui 与 i18n，但桌面 runner 固定唯一真人并依赖全局数据库与模型设置。用户要求 Web 响应式、桌面与 Web 同桌，并明确通过协议和适配器复用逻辑。

## 可行选项

分别演进本地单人和远程多人运行层，初期迁移较少，但会复制行动与结算流程。另一种是提取共享 runtime、protocol、client 和应用层，由各宿主注入传输、存储及系统能力；初期需要消除单人假设，但跨端规则只有一个来源。

## 决定与理由

采用共享运行核心与命令事件协议，权威 runtime 在 Electron 本地 Node 或远程 WS Node 中运行。用户最新认可整体分析方向。storage 定义领域接口，由 SQLite 与 IndexedDB 适配；前端不直接依赖 Electron。

## 后果

事件消费配合快照恢复，不要求整个系统事件溯源。规则、应用与宿主分开；单人和多人是同一运行核心的配置。实际包边界和迁移步骤在方案中明确，现有实现尚未重构。
