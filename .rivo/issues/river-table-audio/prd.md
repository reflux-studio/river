# River 牌局音效需求

依据：用户在当前聊天提出的音效需求；[现状调查](research/current-audio.md)。待决选择统一记录在 [产品决定](product-decisions.md)，本稿按其中建议描述目标行为。

## 问题与目标

当前牌局主要通过画面和文字反馈行动。用户希望筹码、过牌、弃牌、轮到自己和 All-in 等重要事件可以听见。首版补齐牌桌动作反馈与操作提醒，让玩家在阅读教练内容、观察对手或等待模型返回时，更容易跟上牌局节奏。

本次没有量化收益基线。验收以事件覆盖、触发正确、可关闭以及实际试听为依据。声音是现有视觉与文字反馈的补充，静音后仍能完整操作与理解牌局。

## 范围与音效表

适用于桌面端自由局、教练局、引导局，玩家和 AI 的实际行动均覆盖。首版不扩展官网自动演示、历史回放、角色语音、教练朗读、背景音乐、聊天通知或普通按钮点击声。

采用用户确认的 Kenney Casino Audio，保持真实牌桌风格。声音可以复用同一类音源并做轻微变化，不要求每个事件采用独立素材。音量和长度须在完整牌局中试听平衡。包内是否包含合适的敲桌与操作提醒仍需核对，缺口处理见产品决定 D6。

| --- | --- | --- |

## 触发与干扰控制

1. 声音反映已经发生的牌局事实。失败、无效、重复点击或仅修改下注金额不播放行动成功音。快捷键和鼠标产生相同结果时声音一致。
2. 每个实际行动只播放一次。同类连续行动应分别识别，不能因为文字相同而漏播；视图重渲染、教练流式输出、语言切换、窗口缩放不重复播放。
3. 每个玩家决策点只提醒一次。教练讲解未完、提问期间、模型故障、已弃牌、All-in 等不可操作时不提醒；同一决策点提问再恢复不重播提醒。教练完成、跳过或失败后若已允许操作，该决策点仍应获得首次提醒。
4. 进入应用恢复快照、回到牌桌、切换页面、重新开启声音均不回放历史。新开桌的真实首次发牌应播放，与恢复快照区分。
5. 视觉特效 full/lite/off 不影响音效开关。关闭动画仍能获得行动声和操作提醒。
6. 同次 All-in 使用一段完整声音表达。同批收注、多人派奖合并；轮到你提醒与较响桌面声发生冲突时，提醒保持清楚。快速模式不堆积过期声音，长期等待模型返回时没有循环催促。
7. 活跃牌局的声音不因窗口失焦、最小化或切换应用页面而关闭。静音由声音设置决定；离桌、换桌或切手时取消失效序列。回来不补播历史。
8. 声音在离线环境下可用，不新增模型调用。加载或播放失败不影响动作、发牌、教练或下一手推进，也不连续弹错误提示。

## 后台轮到你通知

用户已确认：后台保持音效，后台轮到玩家时增加系统通知弹窗。窗口后台、最小化或隐藏时，新决策点真正允许玩家操作后发出通知；教练锁定时不发。建议应用前台但在其他页面时也通知，正在看牌桌时不额外弹窗。焦点判定只用于通知，不用于静音。

建议标题为 River，正文为“轮到你了”，不展示底牌或模型内容。同一决策点最多通知一次；提问恢复、流式输出、焦点反复变化不重复通知。若就绪时仍在看牌桌，随后切后台且尚未行动，可通知一次。

建议点击通知时恢复应用并定位仍有效的牌桌；已离桌或换桌时只恢复应用。动作完成、换桌、离桌时清理可清理的旧通知。权限被拒绝、通知不支持或系统勿扰抑制展示均不阻塞牌局。通知不再额外触发一次应用提示音；系统通知声优先关闭，平台限制需开发验证。

## 设置与入口

设置页提供“音效”开关、0–100% 主音量和“试听”入口；牌桌提供直接静音/恢复入口。中文与英文界面均有对应标签。

建议新安装和旧版升级缺省为开启、50% 音量。设置立即生效并在重启后保留。静音保存原有音量，恢复时沿用；0% 不出声。试听为用户主动操作，在设置页允许播放，但遵守音效开关和音量；关闭音效或音量为 0 时说明当前无声状态。关闭音效立即停止在播及待播声音。

## 验收标准

| 编号 | 场景 | 可判定预期 |
| --- | --- | --- |
| A1 | 一手包含普通过牌、弃牌、跟注、下注与加注 | 实际完成的每个行动各有对应声音；仅点击、失败提交和输入金额无行动音 |
| A2 | All-in 加注、All-in 跟注、短码盲注 | 各实际 All-in 一次强调，无同动作普通筹码音重复叠加 |
| A3 | 连续两人过牌、同一玩家跨街再次过牌 | 每次都能听见；重复推送同一事件不会多播 |
| A4 | 新开桌首手、下一手、翻牌、转牌、河牌、All-in 后自动发完公共牌 | 实际发牌有声音，先后顺序与可见事件一致，无重复序列或积压 |
| A5 | 自由局到玩家；教练局先锁定后解锁；同一决策点提问恢复 | 真正可操作时首次提醒；锁定期间不提醒，同一决策点不重复 |
| A6 | 净盈利、净亏损、零收益平分、多边池、未跟注筹码返还 | 派奖合并；仅净盈利触发正向点缀；返还不误报胜利 |
| A7 | 静音/恢复、0%/50%/100%、重启应用、旧设置缺字段 | 音量与开关按本稿规则生效；静音立即停播，配置持久化且旧配置可读取 |
| A8 | 特效设为 off；应用恢复、语言切换、页面往返、教练流式输出 | 特效关闭仍有声音；非新牌局事件不重播音效 |
| A9 | 活跃牌局失焦、最小化或切换页面后恢复；随后离桌 | 后台仍按设置播放实时音效，不补播历史；离桌后停播 |
| A10 | 官网自动演示、历史回放；音源加载/播放失败；离线运行 | 官网和回放保持静音；失败不阻塞牌局；本地音源可离线工作 |
| A11 | 完整快节奏牌局与教练局实际试听 | 过牌、弃牌、筹码、All-in、操作提醒可分辨；无削波爆音、明显时序错位和过期声音堆积；记录实际试听环境和结果 |
| A12 | 后台轮到玩家、教练解锁、反复切前后台、点击通知、拒绝系统通知权限 | 就绪且未看牌桌时每决策点最多一条通知；锁定时不发；点击恢复应用和有效牌桌；权限拒绝不阻塞牌局 |
